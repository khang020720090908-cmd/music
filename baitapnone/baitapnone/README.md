# SmartStudy — Hệ Thống Ôn Tập Trắc Nghiệm

Ứng dụng web hỗ trợ học tập và làm bài kiểm tra trực tuyến với 3 dạng câu hỏi (Trắc nghiệm 4 lựa chọn, Đúng/Sai, Trả lời ngắn).

## Cài đặt và chạy ứng dụng

```bash
pip install -r requirements.txt
python app.py
```

Truy cập tại: `http://127.0.0.1:5000`

### Tài khoản mặc định
- **Quản trị viên**: `admin` / `admin123`
- **Học viên**: `hocsinh` / `hocsinh123`
